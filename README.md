# Автоматизированная система поддержки проекта «ВКР как стартап»

**Автор:** Севастьянов Артём Алексеевич, МУ им. С.Ю. Витте, 09.03.03 «Прикладная информатика» (КИС)
**Тема ВКР:** «Разработка автоматизированной системы поддержки проекта "ВКР как стартап" на платформе 1С:Предприятие»

## О проекте
Конфигурация 1С:Предприятие 8.3 для автоматизации работы проектного офиса университета:
приём и экспертиза заявок на стартап-проекты, назначение кураторов, контроль этапов,
оценивание по критериям, допуск к защите, аналитическая отчётность.

## Окружение
- Платформа: 1С:Предприятие 8.3 (учебная версия)
- Среда разработки: 1C:EDT

## Развёртывание
1. Установить платформу 1С:Предприятие 8.3.
2. Создать пустую информационную базу (файловый режим).
3. Загрузить выгрузку `СевастьяновАА_82850_ВКРкакСтартап.dt`
   (Конфигуратор → Администрирование → Загрузить информационную базу)
   либо открыть проект в 1C:EDT из этого репозитория.

## Учётные записи (роли)

- Иванова О.С. — роль «Сотрудник проектного офиса»

## Демонстрационный сценарий
1. Справочники → заполнены тестовыми данными (студенты, сотрудники, проекты, этапы, критерии).
2. Документ «Заявка на участие» → «Экспертиза заявки» → «Регистрация проекта».
3. «Назначение куратора» → «План развития проекта» → «Отчёт по этапу» → «Оценка этапа».
4. «Допуск к защите» → «Защита проекта».
5. Отчёты: сводная ведомость, рейтинг проектов, загрузка кураторов (печатные формы).
